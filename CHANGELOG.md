## [0.1.0] - 2026-09-01

### Added

- Initial public preview with the terminal UI, persistent sessions, provider adapters, tool sandbox, approvals, checkpoints, sub-agents, MCP/LSP integrations, repository indexing, plugins, attachments, localization, and cross-platform test matrix.
- Complete English and Russian installation, configuration, usage, troubleshooting, architecture, feature, keymap, security, and contribution documentation.
- Public repository security/support policies and structured contribution templates.
- Code of Conduct, source-generated README animation, and automated native GitHub Release archives with checksums.

### Changed

- Repository packaging now excludes local configuration, build artifacts, release binaries, backups, and internal source dumps.
- Configuration and plugin templates are grouped under `examples/`.
