# Управление DEcode

[English](KEYMAP.md) · [Документация](README.ru.md) · [Использование](USAGE.ru.md)

Мышь и клавиатура вызывают одинаковые typed actions. `Tab` и `Shift+Tab` перемещают фокус, стрелки двигают выбор в списках, `Space` переключает значение, `Enter` активирует его, а `Esc` закрывает или отменяет без применения, если это разрешено текущим диалогом.

Footer, меню **Помощь** и палитра команд `/` являются источником истины для текущих экрана и сборки.

## Глобальные сочетания

| Клавиша | Действие |
|---|---|
| `F10` | Открыть menu bar |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Следующая/предыдущая основная вкладка |
| `/` в пустом composer | Открыть палитру команд |
| `@` | Открыть браузер вложений, не удаляя введённый текст |
| `Ctrl+N` | Создать новую сессию |
| `Ctrl+O` | Открыть менеджер сессий |
| `Ctrl+Z` | Открыть checkpoint rewind |
| `Ctrl+M` | Выбрать модель, reasoning effort и бюджет контекста |
| `Ctrl+K` | Открыть менеджер MCP |
| `Ctrl+L` | Открыть language intelligence/LSP |
| `Ctrl+B` | Открыть индекс/поиск репозитория |
| `Ctrl+G` | Открыть режимы работы и постоянную цель |
| `Ctrl+J` | Открыть follow-ups Queue & Steer |
| `Ctrl+Y` | Открыть read-only side question (`/btw`) |
| `Ctrl+Shift+T` | Открыть или создать интерактивную вкладку Terminal |
| `End` | Вернуться к новейшему выводу чата и следовать за ним |
| `F6` | Поставить активный ход на паузу или продолжить приостановленный |
| `F8` | Отменить приостановленный ход |
| `F7` | Покормить или разбудить Pixel во время простоя |
| `Ctrl+R` | Сбросить текущий запуск через urgent control |
| `Ctrl+C` / `Esc` | Прервать активный ход или выйти из текущего idle flow |

## Composer

| Клавиша или действие | Результат |
|---|---|
| `Enter` | Отправить текст и выбранные вложения |
| `Alt+Enter` | Добавить новую строку |
| Стрелки | Переместить курсор; вертикальные стрелки работают в многострочном тексте |
| `Home` / `End` | Перейти к началу/концу текущей строки |
| `Backspace` / `Delete` | Безопасно удалить предыдущую/следующую grapheme |
| Вставка | Вставить текст, прикрепить абсолютные пути, преобразовать большой текст во вложение или получить изображение из буфера |
| Клик по chip вложения | Выбрать/удалить подготовленное вложение через видимое действие |

Когда composer пуст, `Tab` и `Shift+Tab` выбирают следующую или предыдущую карточку инструмента. После этого `Enter` раскрывает или сворачивает карточку, а не отправляет пустое сообщение.

## Палитра команд

- Ввод фильтрует встроенные и пользовательские slash commands.
- `Up` / `Down` выбирает строку.
- `Home` / `End` выбирает первую/последнюю строку.
- `Tab` / `Shift+Tab` перемещает фокус между списком и кнопками.
- `Enter` выполняет действие в фокусе.
- `Esc` закрывает палитру без запуска.

Палитра открывает sessions, rewind, providers, MCP, LSP, индекс репозитория, privacy, permissions, auto-approval, usage, notifications, review, side chat, Queue & Steer, modes, instructions, skills, plugins, hooks, вкладки, терминалы, sidebars и переход к последнему сообщению.

## Браузер вложений

| Клавиша или действие | Результат |
|---|---|
| Ввод | Фильтровать текущий каталог по имени или пути |
| `Up` / `Down` | Выбрать видимую строку |
| `Home` / `End` | Выбрать первую/последнюю видимую строку |
| `Enter` на каталоге/shortcut | Перейти в него |
| `Backspace` при пустом фильтре | Перейти в родительский каталог |
| `Space` на файле | Добавить/удалить его из множественного выбора |
| `Enter` или **Прикрепить** | Прикрепить выбранные файлы либо текущий файл, если ничего не отмечено |
| `Esc` | Закрыть без добавления файлов |

Доступные shortcuts включают workspace, домашний каталог, Рабочий стол, Загрузки, корни/диски и родительский каталог. Клики мыши выбирают строки и активируют те же кнопки Закрыть/Прикрепить.

## Общие правила диалогов

| Клавиша | Действие |
|---|---|
| `Tab` / `Shift+Tab` | Следующий/предыдущий доступный элемент |
| Стрелки | Навигация по спискам или переключение panes диалога |
| `PageUp` / `PageDown` | Прокрутка длинного содержимого, где поддерживается |
| `Home` / `End` | Первая/последняя строка или граница содержимого |
| `Space` | Переключить checkbox или бинарное решение hunk |
| `Enter` | Активировать кнопку/элемент в фокусе |
| `Esc` | Закрыть или отклонить без применения |

Диалоги подтверждения и патчей привязывают решение к точным turn, action и digest. Для длинного содержимого approval разблокируется только после просмотра последней строки.

## Чат и карточки инструментов

- Колесо мыши прокручивает историю, когда указатель находится над чатом.
- Клик по tool card выбирает её и открывает context menu.
- Меню карточки раскрывает подробности или вставляет ссылку на call/result в composer.
- `End` снова включает follow-latest после ручной прокрутки.
- Недоверенный текст tool/code очищается до syntax highlighting.

## Сессии и списки

Стрелки перемещают выбор, колесо прокручивает список и удерживает выбранную строку видимой. `Home` и `End` переходят к границам списка. Action buttons доступны через `Tab` и напрямую мышью. Точный набор зависит от экрана: open/resume, fork, rename, pin, archive, restore, search или close.

## Вкладка Agents

Дерево агентов прокручивается отдельно от detail pane. Колесо над деревом или клавиатурная навигация показывают скрытых за экраном descendants; выбор и визуальная позиция прокрутки двигаются вместе. Message, stop, review, raise budget и cancel recovery появляются только тогда, когда допустимы для состояния выбранного агента.

## Диалог Usage

Выберите deployment и активируйте **Задать точный тариф**. Введите три ставки USD за миллион токенов, затем используйте **Сохранить и пересчитать** либо отмену. Все поля и действия доступны через mouse hit regions и `Tab`/`Shift+Tab` вместе с `Enter`/`Esc`.

## Интерактивная вкладка Terminal

Вкладка Terminal владеет raw keyboard и paste input отдельно от model command runner.

| Клавиша | Действие |
|---|---|
| `Ctrl+Shift+T` | Создать/открыть терминал |
| `F6` | Переключить raw terminal input и toolbar controls |
| `Ctrl+Shift+X` | Остановить активный terminal process |
| `Ctrl+Shift+W` | Закрыть активный терминал |
| Колесо мыши | Прокрутить историю, если child process не перехватывает mouse input |

Mouse sequences передаются только тогда, когда дочернее приложение включает поддерживаемый terminal mouse mode.
