# Документация DEcode

[English](README.md) · [README проекта](../README.ru.md)

Это оглавление всей документации. Корневой README показывает кратчайший путь от клонирования до первой задачи, а здесь собраны подробные инструкции для работы и разработки.

## Руководства пользователя

| Руководство | Содержание |
|---|---|
| [Установка](INSTALLATION.ru.md) | Требования Windows, Linux и macOS, сборка из исходников, установка через Cargo, обновление и проверка сборки |
| [Настройка](CONFIGURATION.ru.md) | Приоритет настроек, провайдеры, ключи, endpoint, контекст, разрешения, интеграции и логи |
| [Использование](USAGE.ru.md) | Первая задача, composer, вложения, подтверждения, сессии, контекст, режимы, Pixel, терминалы и восстановление |
| [Решение проблем](TROUBLESHOOTING.ru.md) | Диагностика запуска, провайдера, контекста, вложений, сессий и терминала |
| [Управление](KEYMAP.ru.md) | Полное управление клавиатурой и мышью, диалоги, composer и терминал |
