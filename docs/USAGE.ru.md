# Использование DEcode

[English](USAGE.md) · [Документация](README.ru.md) · [Настройка](CONFIGURATION.ru.md) · [Управление](KEYMAP.ru.md)

DEcode — терминальный coding-агент. Вы выбираете workspace, описываете результат, проверяете запрошенные разрешения и контролируете изменения обычными средствами Git.

## Запуск в workspace

Запустите установленную программу с явным каталогом проекта:

```powershell
decode.exe --workspace "D:\projects\my-app"
```

```bash
decode --workspace /home/user/projects/my-app
```

Для воспроизводимой конфигурации добавьте `--config`:

```text
decode --config /абсолютный/путь/config.toml --workspace /абсолютный/путь/к/проекту
```

Workspace должен существовать заранее. Все параметры текущей сборки выводит `decode --help`.

## Выполнение первой задачи

1. Откройте чистый либо намеренно изменённый Git working tree.
2. Опишите желаемый результат, важные ограничения и способ проверки.
3. При необходимости прикрепите примеры или исходные материалы.
4. Проверяйте запросы на выполнение команд и применение патчей; разрешайте только понятное точное действие.
5. Дождитесь завершения хода, затем прочитайте итоговый ответ и Git diff.
6. Перед коммитом запустите тесты самого проекта.

Хороший запрос описывает результат, а не навязывает каждую деталь реализации. Для бага укажите точную ошибку, ожидаемое поведение, платформу и минимальный способ воспроизведения.

## Composer

- `Enter` отправляет текущее сообщение.
- `Alt+Enter` добавляет новую строку.
- `/` в пустом composer открывает встроенные и пользовательские команды.
- `@` открывает файловый браузер, даже если текст уже введён.
- `Ctrl+V` вставляет обычный текст или получает изображение напрямую из системного буфера.
- Очень большой вставленный текст становится `.txt`-вложением и не обрезается молча.

В одном ходе можно одновременно отправить текст и несколько файлов. До отправки вложения показаны отдельными удаляемыми chips.

## Прикрепление файлов

Браузер `@` позволяет переходить в workspace, домашний каталог, Рабочий стол, Загрузки, родительские каталоги, корни файловых систем и диски Windows. Ввод фильтрует список, стрелки выбирают строку, `Enter` открывает каталог, а `Space` отмечает несколько файлов. После выбора активируйте кнопку **Прикрепить**.

Другие способы:

- вставить один или несколько абсолютных путей;
- вставить изображение через `Ctrl+V`;
- перетащить файлы из файлового менеджера в терминал, который преобразует drop в пути.

DEcode принимает изображения, документы, текст, аудио и видео, но фактически поддерживаемые типы определяются выбранными провайдером и моделью. Неподдерживаемый тип отклоняется до запроса. Файлы копируются в content-addressed хранилище сессии, ограничиваются по размеру и количеству и повторно проверяются по digest перед отправкой. Исходный путь из Temp или Загрузок не передаётся модели вместо содержимого.

Стандартные ограничения одного хода: 16 файлов, 50 МиБ на файл и 50 МиБ суммарно. Тип проверяется по содержимому и метаданным; одно расширение не разрешает исполнение и не обходит проверку возможностей провайдера.

## Чтение хода

В чате отдельно показаны сообщения пользователя, reasoning/status модели, вызовы инструментов, результаты, ошибки и финальный ответ. Карточку инструмента можно выбрать мышью либо клавишами `Tab` и `Shift+Tab`, пока composer пуст. Откройте карточку, чтобы увидеть детали или сослаться на вызов/результат в следующем сообщении.

Над финальным ответом отображаются накопленные время, токены и оценочная стоимость логического хода. Пауза, retry или восстанавливаемая ошибка не должны сбрасывать эти суммы до значений последнего отдельного запроса.

Клавиша `End` возвращает к новейшему выводу после прокрутки вверх. Пока вы читаете старую историю, автоматический переход вниз остаётся приостановленным.

## Подтверждения и ревью патчей

Подтверждение команды привязано к показанному точному действию. Проверьте команду, рабочий каталог, причину и запрошенную область. Разрешение на сессию действует только для своей точной версии правила и не является общим обходом shell-проверок.

Патчи проверяются по отдельным hunks. Примите или отклоните каждое видимое изменение, прокрутите длинный текст до конца и только затем подтвердите. При rewind ручные правки после checkpoint проверяются на конфликт.

Оставляйте `agent.shell.confirmation_mode = "always"`, пока намеренно не настроите более узкие доверенные правила.

## Пауза, продолжение, прерывание и отмена

- `F6` ставит активный ход на паузу и продолжает приостановленный.
- `F8` отменяет приостановленный ход вместо продолжения.
- `Ctrl+C` или `Esc` прерывает активную работу в зависимости от текущего экрана.
- `Ctrl+R` сбрасывает текущий запуск через срочный канал управления.

Пауза сохраняется на подтверждённой причинной границе. При продолжении начинается новый запрос к провайдеру из записанного состояния; продолжить закрытый SSE/TCP-поток ровно со следующего токена невозможно. Незавершённый потоковый вызов инструмента не считается выполненным. Если эффект внешней команды неизвестен, DEcode сообщает об этом, а не повторяет её вслепую.

## Сессии

`Ctrl+N` создаёт сессию, `Ctrl+O` открывает менеджер. Сессию можно продолжить, разветвить, переименовать, закрепить, архивировать и найти через поиск. У каждой сессии собственные история, ссылки на вложения, бюджет контекста, usage ledger, checkpoints и данные восстановления.

Журналы сессий — append-only JSONL с контрольными суммами. После аварийного завершения повреждённый оборванный хвост может быть отброшен, но ранняя валидная история не переписывается. Запуск того же бинарника от другого пользователя, с другим конфигом или каталогом сессий может показать другой список; для непрерывности используйте одинаковые `--config` и `agent.session_dir`.

## Модель, reasoning и контекст

Runtime picker открывается через `Ctrl+M`. В нём выбираются модель или deployment, reasoning effort и активный бюджет контекста.

- Выбранный бюджет относится к текущей сессии.
- После изменения он также становится значением по умолчанию для новых сессий.
- При возврате в старую сессию восстанавливается сохранённое для неё значение.
- `max_context_budget` — только предел UI/runtime; он не увеличивает реальное окно модели.

Когда запрос приближается к бюджету, DEcode сжимает старую восстанавливаемую историю, сохраняя исходную задачу и новейшую полную причинную группу инструментов. Сжатие отмечается в чате. Если даже обязательное недавнее состояние не помещается, запрос завершается явной ошибкой вместо скрытой потери контекста.

## Режимы работы

Режимы и постоянные цели открываются через `Ctrl+G`. Plan, Explore, Review, Goal и Deep Thinking меняют подход агента, но не добавляют разрешений на файлы, shell, MCP или сеть. Комбинируйте режимы только тогда, когда их поведение нужно текущей задаче.

Queue & Steer (`Ctrl+J` вне редактирования composer) принимает уточнения для активной работы. Side Question (`Ctrl+Y`) задаёт read-only вопрос и не превращает его в указание менять проект.

## Pixel

Pixel — необязательная панель маскота над чатом. Его состояние влияет только на отображение, но не на качество модели, разрешения или подсчёт токенов.

- Pixel включается и выключается в меню **Вид**; настройка сохраняется между сессиями.
- `F7` кормит или будит Pixel только во время простоя.
- Во время генерации Pixel показывает состояние runtime, и кормление недоступно.

## Вкладка Terminal

Вкладка Terminal запускает пользовательские интерактивные PTY отдельно от команд модели. Новый терминал открывается через `Ctrl+Shift+T`. Внутри вкладки `F6` переключает прямой ввод и управление toolbar, `Ctrl+Shift+X` останавливает активный процесс, а `Ctrl+Shift+W` закрывает терминал.

Текст, введённый в интерактивный терминал, не считается разрешением на model tool call. Для команд модели продолжают действовать отдельные sandbox и confirmation policy.

## Необязательные интеграции

Меню и палитра `/` открывают:

- MCP-подключения и разрешения отдельных инструментов;
- установленные LSP-серверы;
- индекс репозитория и необязательные удалённые embeddings;
- skills, плагины, hooks, пользовательские команды и профили агентов;
- работу с GitHub pull request через авторизованный `gh` CLI;
- субагентов, review, уведомления, usage, privacy и auto-approval.

Включайте интеграции по одной и проверяйте их границы доверия. DEcode не устанавливает LSP-бинарники автоматически, а конфигурация проекта не может незаметно добавить привилегированный MCP-сервер или исполняемый hook.

## Безопасный выход

По возможности прервите или поставьте активную работу на паузу до закрытия терминала. После принудительного завершения процесс восстанавливается от последней durable-границы, но ни один терминальный агент не гарантирует завершение внешней программы после kill процесса или отключения питания.

Перед коммитом изменений агента выполните:

```bash
git status --short
git diff --check
git diff
```

Далее прочитайте [полное управление](KEYMAP.ru.md), [модель безопасности](SECURITY.ru.md) или [руководство по решению проблем](TROUBLESHOOTING.ru.md).
