## [0.1.0] — 2026-09-01

### Добавлено

- Начальная публичная preview-версия с терминальным UI, постоянными сессиями, provider adapters, tool sandbox, подтверждениями, checkpoints, субагентами, интеграциями MCP/LSP, индексом репозитория, плагинами, вложениями, локализацией и кроссплатформенной матрицей тестов.
- Полная документация по установке, настройке, использованию, диагностике, архитектуре, возможностям, управлению, безопасности и участию в разработке на английском и русском языках.
- Публичные политики безопасности/поддержки и структурированные шаблоны для участников.
- Кодекс поведения, собранная из реального UI анимация README и автоматические нативные архивы GitHub Release с checksums.

### Изменено

- Из package репозитория исключены локальная конфигурация, результаты сборки, release binaries, резервные копии и внутренние dumps исходников.
- Шаблоны конфигурации и плагина сгруппированы в `examples/`.
